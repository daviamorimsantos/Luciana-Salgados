# Luciana Salgados — site de pedidos

Site estático responsivo, inspirado na referência visual enviada: grandes faixas promocionais, catálogo em cards, destaque de produtos, identidade preta/dourada e foco em conversão.

## Publicar na Vercel
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Na Vercel, importe o repositório.
4. Como é um site estático em HTML/CSS/JS, não precisa de comando de build. Deixe Build Command vazio e Output Directory como `.` (ou use as configurações automáticas para site estático).
5. Faça Deploy.

## Observações para revisar antes de publicar
- Confirme se todos os pacotes de 15 unidades custam R$ 30,00 e se o cento frito custa R$ 100,00.
- Confirme se o nhoque de 1 kg também custa R$ 30,00.
- Confirme o texto e os sabores dos produtos.
- O botão envia o pedido para o WhatsApp; disponibilidade, entrega e pagamento são confirmados diretamente com a Luciana.
- O número de WhatsApp está no arquivo `app.js` e nos links `wa.me` do `index.html`.
- Não há banco de dados nem painel administrativo nesta versão.
